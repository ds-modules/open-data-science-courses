# Data 9 Adoption

This page covers what instructors need to adopt Data 9 at their institution.

## Instructor resources

For instructors adopting Data 9, we provide:

- **[Instructor repository](https://github.com/ds-modules/cs-9-dev)** — assignment solutions and autograder configuration ([ds-modules/cs-9-dev](https://github.com/ds-modules/cs-9-dev) on GitHub). Contact [ds-help@berkeley.edu](mailto:ds-help@berkeley.edu) with your GitHub username to request access.

We do **not** currently provide a Canvas course shell for Data 9 (unlike Data 6). You can link the public notebooks from your own LMS or course site, and use the instructor repository for grading setup.

```{warning}
Please do not distribute solutions to students. Keeping instructor materials private helps protect the integrity of the course for all adopting institutions.
```

## Student materials

All core student materials are openly available. Link these from your LMS or course site:

- **[Course website (JupyterLite)](https://arianag27.github.io/CS-9/)** — weekly schedule with lecture demos and labs in the browser
- **[Online textbook](https://ds-modules.github.io/ecc-cs9-textbook/)** — source: [ds-modules/ecc-cs9-textbook](https://github.com/ds-modules/ecc-cs9-textbook)
- **[Lecture materials](slides.md)** — slide decks and lecture notebooks organized by topic
- **[Labs and projects](https://github.com/ds-modules/ecc-cs9)** — Jupyter notebooks for projects and hands-on work

See the [Intro](intro.md) page for a full overview of the course.

## Getting help

**Questions about adopting Data 9?** Email [ds-help@berkeley.edu](mailto:ds-help@berkeley.edu) with your GitHub username to request access to the instructor repository.
